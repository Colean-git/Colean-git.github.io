# 刘超超个人学术主页

这是 `Colean-git.github.io` 的第一版可运行网站（V0.1），采用原生 HTML、CSS 和少量 JavaScript 构建。

## 信息架构

- 首页 Home
- 关于我 About
- 研究方向 Research
- 学术成果 Publications
- 科研与实践项目 Projects
- 企业走访与产业实践 Fieldwork
- 学生培养 Students
- 教学 Teaching
- 社会服务 Service

## 设计原则

- 中文为主，采用图书/章节式结构
- 桌面端使用左侧章节目录，移动端使用折叠目录
- 不依赖大型前端框架，便于长期维护
- 只公开已有依据且适合公开的信息

## 本地预览

在仓库根目录启动任意静态文件服务器，然后访问 `index.html`。直接打开文件也可浏览主要内容。

## 后续计划

V0.2 将继续完善代表性成果、企业走访档案、学生项目、教学案例和页面级研究专题。
